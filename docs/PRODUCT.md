# 产品与边界

FeishuFS 面向需要用本地工具读取飞书/Lark 知识库的用户，不替代飞书编辑器。

## 产品取舍

| 选择 | 收益 | 代价 / 边界 |
| --- | --- | --- |
| 一次挂载一个完整知识库 | 文档链接即可定位空间，保留目录关系 | 不支持指定子树或合并多个空间；只能读取有权限的内容 |
| 只读 | 不修改云端文档，避免双向同步冲突 | 不能在挂载目录中编辑、创建或删除文档 |
| 通用文件格式 | 普通文件 API、搜索和 AI 工具可直接使用 | 不追求还原飞书页面的完整布局和交互 |
| 内容按需获取 | 启动不必下载整座知识库 | 首次读取需要联网；不支持离线首次挂载 |
| 轮询目录、独立缓存内容 | 目录与正文可分别更新，失败时保留旧数据 | 最终一致，不保证实时更新或单次打开的固定版本 |

## 文件映射

挂载根是空间本身，没有正文。节点按**实际可见子页面**决定是目录还是文件：

| 飞书对象 | 有子页面 | 没有子页面 |
| --- | --- | --- |
| `docx` | `标题/index.md` | `标题.md` |
| 旧版 `doc` | `标题/index.docx` | `标题.docx` |
| `sheet` / `bitable` | `标题/标题.<子表名>.csv` | `标题.<子表名>.csv` |
| `file` | `标题/index.<扩展名>` | `标题.<扩展名>` |
| 暂不支持的类型 | `标题/index.md` | `标题.md`，说明原因和云端链接 |

```text
<mountpoint>/
├── 快速开始/
│   ├── index.md
│   └── API 说明.md
├── 数据报表.收入.csv
├── 数据报表.支出.csv
└── 附件.pdf
```

- 表格每个工作表 / 数据表一份 CSV，不生成 `index.csv` 或 XLSX；可见子表列表为空时生成 Markdown 说明。
- 清理跨平台非法字符和大小写不敏感的同级冲突。新重名项添加短 ID 后缀，不覆盖已有文件。
- 普通文件标题已有相同扩展名时不重复追加；原文件无法从标题取得安全扩展名时使用 `.bin`。
- 云端增删、移动、改名及叶子 / 分支转换，在下一次成功目录刷新后可见。

## 内容保留

| 内容 | 当前行为 |
| --- | --- |
| Docx 正文 | 按 XML 结构转为 Markdown，保留段落、标题、强调、列表、引用、代码和链接；未支持的特殊块保留说明及原始结构 |
| 文档内表格 | 简单表格转为 Markdown；合并单元格等未支持结构保留原始 XML |
| 画板 | 有非空 Mermaid 源码时原位保留代码，否则下载图片并引用挂载内文件；不从图片反推源码，不裁剪白边 |
| 独立表格 | 仅将整格的已知飞书 / Lark 文档与附件 URL 改为相对本地链接；其他单元格字节、BOM、原有引号与换行保持原样；不保留公式源码、样式、图表或布局 |
| 文件节点 | 原文件按需下载，不改写二进制内容；原路径和 `.feishufs-assets/<附件 inode>/<文件名>` 共享同一下载与缓存 |

表格不按视图或筛选视图分别导出。读取 CSV 只改写链接，不额外下载附件字段的二进制内容；访问改写后的资产路径时才下载。隐藏工作表仍列入清单；隐藏行列、筛选和复杂字段的具体 CSV 表示取决于服务端，尚未完整验证。非 UTF-8 编码或引号结构不合法的 CSV 整体保留原始字节，不尝试改写。

画板资产在成功读取正文后按需出现，不会让叶子文档变成目录；附件资产入口从文件节点清单生成，列出入口不代表已下载。`inspect` 不预取正文或附件。

### 资产落盘

- 对外的资产入口只有 `<mountpoint>/.feishufs-assets`，例如 `wiki/.feishufs-assets`；启动摘要显示这个入口，不再默认创建工作目录下另一个 `.feishufs-assets`。
- 成功下载的附件和画板图片落盘到内部缓存。Linux 默认使用 `$XDG_CACHE_HOME/feishufs`，未设置时使用 `$HOME/.cache/feishufs`。可用 `--cache-dir` 显式指定；无法确定用户缓存位置时必须显式指定，不回退到工作目录或共享临时目录。缓存目录必须与挂载点互不包含，避免写入只读挂载自身。
- 内部缓存按 `<cache-dir>/<链接域名>/<space_id>/files/<十六进制 obj_token>/<文件名>` 隔离附件；画板图片使用同一缓存下的 `whiteboards/<十六进制 token>/<图片名>`。这些是后端存储布局，不用于 Markdown 或 CSV 链接。
- 下载仍按需进行，Markdown 和 CSV 的附件链接均指向挂载内的相对资产路径；原附件路径保留兼容入口，两种入口共享下载、缓存和失败冷却。
- 临时文件完整写入并刷新后原子替换磁盘副本，避免下载或写入失败截断旧文件。落盘失败按内容获取失败处理，不把只存内存的结果报告为成功。
- 磁盘副本在卸载、节点删除或改名后保留，不自动清理；暂无总容量限制，也不从历史副本恢复跨挂载缓存。内容仍按 TTL 重新获取。宿主机副本可由用户管理，不回写云端。
- 库调用方通过 `FsOptions.asset_directory` 显式启用落盘；默认不写磁盘。

普通内嵌图片 / 附件的全面本地化、同步块展开及 draw.io 专用转换尚未实现；本能力覆盖知识库 `file` 节点，不能把它或画板支持等同于所有嵌入对象均已支持。

### Markdown 与 CSV 链接

- 挂载范围内的已知文档链接改写为相对本地路径，附件链接统一指向 `.feishufs-assets` 下的入口；范围外、未知目标和 Markdown 代码示例保持原样。
- CSV 仅改写整个单元格为 URL 的值，包括 `PDF` / 读书笔记等列；不扫描普通文本、Markdown 片段或复杂字段内部的 URL。改写后若路径含逗号等 CSV 特殊字符，会为该单元格补上必要的引号与转义，不重新序列化整份表格。以公式起始字符开头的本地路径加 `./` 前缀，避免被电子表格工具当作公式。
- 表格链接的 `?sheet=<ID>` / `?table=<ID>` 指向对应 CSV；未知子表保持云端链接，未指定时选择按子表 ID 排序的首个 CSV。
- 本地路径中的 `%` 和 `#` 编码，原链接的 fragment 保留，跟踪类 query 丢弃。云端改名或移动后，从缓存原文重新计算相对链接。

## 更新与故障

- 入口文档仅用于启动时定位空间；之后固定该空间，不因入口文档删除或移动而切换目标。
- 目录刷新完成后才等待下一轮；实际周期包含遍历耗时。失败会退避，大知识库受 API 配额影响，不承诺严格的一分钟更新上界。
- 打开文件或查询元数据时检查内容 TTL；普通 `read()` 不主动检查过期。参数见 [README](../README.md#常用参数)。
- API 暂时失败时保留旧目录 / 旧缓存；没有可用内容时返回 I/O 错误。内容失败有重试冷却，不重置最后成功获取时间。
- 缓存不按打开句柄固定版本；其他访问或链接重渲染可能改变正在读取的共享内容。

## 平台与非目标

仅支持 Linux，使用 FUSE 只读挂载，文件 / 目录权限为 `0444` / `0555`，写入及修改操作被拒绝。

当前不包含：写回同步、离线首次挂载、GUI / 托盘 / 常驻服务、多知识库合并、macOS / Windows 支持。后续事项见[路线图](ROADMAP.md)。
