# 路线图

当前能力见[产品与边界](PRODUCT.md)。以下是建议推进顺序，不代表发布日期或交付承诺。

## 优先补齐

| 事项 | 完成标准 |
| --- | --- |
| 正文与画板的失败策略 | 先确定部分成功、旧版本保留、重试与一致性规则，再实现和测试 |
| 内容保真验证 | 用授权样例核验复杂 CSV 字段、隐藏行列 / 筛选、合并单元格及不同文本绘图组件，公开实际边界 |

## 后续候选

- 普通内嵌图片 / 附件本地化、同步块展开、draw.io 等嵌入对象处理。
- 大知识库的遍历效率、API 限流和资源预算。

## 尚未定案

- 一张图片失败时，是否仍提供正文？错误如何呈现？
- 正文、图片与目录来自不同修订时，是否整体发布，旧版本保留多久？
- 资产格式 / token 变化或资源消失时，路径和引用如何迁移？
- 是否限制正文与资产合计大小、资产数量，或协调跨进程 API 配额？
- 是否需要按打开句柄固定内容版本？当前不改造 FSK 或引入本地文件快照。

[当前非目标](PRODUCT.md#平台与非目标)不自动进入路线图；实现前需先讨论范围与取舍。
